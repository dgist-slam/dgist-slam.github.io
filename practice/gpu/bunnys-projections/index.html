아직 측정하지 않았습니다.

CPU: worker 내 투영 + Z-buffer + 색 변환. GPU wall: draw + RGBA readback 완료까지. GPU timer: 지원 시 GPU 명령 시간만. 네트워크·화면 갱신·worker 메시지 전송은 비교에서 제외됩니다. Frame loop FPS는 브라우저 콜백 간격이며 실제 화면 스캔아웃 측정값이 아닙니다.

내 GPU에서 어떻게 실행되나요?

설치 없이 WebGL2 정점 셰이더와 depth test를 실행합니다. CUDA 실습의 브라우저 버전이며, JavaScript CPU와 WebGL 렌더러의 비교입니다. NVIDIA 전용 CUDA 성능과 직접 비교하지 마세요. AMD / Intel / Apple GPU도 브라우저 지원에 따라 사용할 수 있습니다. 브라우저가 소프트웨어 렌더러를 선택하면 실제 GPU 가속이 아닙니다.

GPU가 감지되지 않으면 브라우저의 하드웨어 가속 설정을 켜고 재시작하세요. WebGL2가 없으면 CPU 모드로 실행됩니다. 모델 다운로드 이후 프레임은 로컬에서 계산하며 별도 서버로 보내지 않습니다. CPU와 GPU의 부동소수점 및 래스터화 차이로 경계 픽셀은 다를 수 있습니다.
